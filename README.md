# Steam Auto Suite

A collection of tools for managing your Steam library.

</div>

## Tools

| Tool | Description |
| - | - |
| [Steam Auto Art](./tools/steam-auto-art/) | Automatically applies your custom Steam artwork to your library. |
| [Steam Auto Collections](./tools/steam-auto-collections/) | Automatically creates and populates your Steam collections. |
| [Steam Auto Favorites](./tools/steam-auto-favorites/) | Automatically populates your Steam favorites. |
| [Steam Auto ID](./tools/steam-auto-id/) | Find a Steam game's App ID by name. |
| [Steam Auto Launch](./tools/steam-auto-launch/) | Automatically applies launch options to your Steam games. |
| [Steam Auto Name](./tools/steam-auto-name/) | Find a Steam game's name by App ID. |

# Disclaimer

Steam Auto Suite is an unofficial project and is not affiliated with, endorsed by, or associated with Valve Corporation or Steam in any way. Some tools use Steam's publicly available endpoints. 

"Steam" is a trademark of Valve Corporation.

Several tools in this suite may read from and write directly to files on your computer (e.g. configuration files or Steam-related files) in order to function. This happens only when you run the tool, it does not run in the background or schedule anything automatically. Please review each tool's documentation before use and ensure you understand what files may be modified.

"Auto" refers to performing repetitive, mundane, and/or lengthy tasks.
